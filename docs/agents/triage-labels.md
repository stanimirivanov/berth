# Triage labels

Use these GitHub labels when a skill names a triage role.

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer evaluation is pending |
| Needs information | `needs-info` | More information is needed from the reporter |
| Ready for an agent | `ready-for-agent` | The work is specified and ready for an agent |
| Ready for a human | `ready-for-human` | A human needs to implement the work |
| Declined | `wontfix` | The maintainer decided against implementing it |
