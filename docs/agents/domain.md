# Berth domain docs

Berth is a single domain context spanning the Angular UI, Cloudflare history
proxy, Neon read service and OCI lifecycle executor.

Before exploring, read the [root glossary](../../GLOSSARY.md) and relevant decisions
in [docs/adr/](../adr/). Use the glossary's terms in issue titles, code and
tests. Surface any conflict with an ADR. Add terms and ADRs as decisions
are settled through the domain-modeling skill.

Use [SPEC.md](../../SPEC.md) for the trial contract and authorization limits.
Dated evidence and operational procedures live under [docs/trial/](../trial/).
